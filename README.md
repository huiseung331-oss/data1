# 🌡️ 서울 기온 상승 분석 (1907–2026)

> **가설:** 1980년을 기점으로 서울의 기온 상승 속도가 가속화되었다

기상청 서울 관측소(지점 108)의 약 120년치 일별 기온 데이터를 분석하여  
1980년 이전과 이후의 기온 상승 패턴 차이를 시각화·통계적으로 검증하는 Streamlit 웹앱입니다.

---

## 📸 주요 화면

| 탭 | 설명 |
|---|---|
| 📈 연도별 추세 | 연도별 산점도 + 기간별 선형 회귀선 + 10년 이동평균 |
| 📊 분포 비교 | 히스토그램 & 박스플롯으로 이전/이후 분포 시각화 |
| 🗓️ 계절별 분석 | 봄/여름/가을/겨울 각각의 기온 추세 비교 |
| 🔬 통계 검정 | 독립표본 t-검정, p-값, 10년 단위 평균기온 바차트 |

## 🗂️ 데이터

- **출처:** [기상자료개방포털](https://data.kma.go.kr) → 지상 관측 → 일별 자료
- **지점:** 108 (서울)
- **기간:** 1907-10-01 ~ 2026-05-31
- **컬럼:** 날짜, 지점, 평균기온(℃), 최저기온(℃), 최고기온(℃)

> CSV 파일은 저작권 문제로 레포에 포함하지 않을 수 있습니다.

## 🔬 분석 방법

- **선형 회귀** — 이전/이후 기간별 기온 상승 속도(°C/10년) 산출
- **독립표본 t-검정** — 두 기간의 평균기온 차이가 통계적으로 유의한지 검증 (p < 0.05)
- **10년 이동평균** — 연도별 변동성을 제거한 장기 추세 확인
- **10년 단위 집계** — 연대별 평균기온 변화 추적
